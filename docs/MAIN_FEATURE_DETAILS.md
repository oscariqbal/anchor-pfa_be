## Main Feature Details
1. Authentication
Ensure that users access the appropriate data and that data is accessed by the appropriate users.

    - Create account
    - View account details
    - Edit account
    - Delete account

2. Transaction Record
Record user's transactions and view all transaction over a specific period

    - Record income
    - Edit income record
    - Delete income record
    - Record expense
    - Edit expense record
    - Delete expense record
    - Record transfer
    - Edit transfer record
    - Delete transfer record
    - Record saving allocation
    - Edit saving allocation record
    - Delete saving allocation record
    - Record saving release
    - Edit saving release record
    - Delete saving release record
    - View record detail
    - View record list
    - View transaction analytics report
    - View AI powered advice on transaction

3. Transaction Planner
Plan user's transactions and view all planned transaction

    - Plan income
    - Edit income plan
    - Delete income plan
    - Plan expense
    - Edit expense plan
    - Delete expense plan
    - Plan transfer
    - Edit transfer plan
    - Delete transfer plan
    - View plan detail
    - View plan list
    - Realize plan
    - Cancel plan

4. Wallet
Classify user's money position based on wallet type exist (bank, cash, e-money), for example "BCA" for bank, "Black Wallet" for cahs, and "DANA" for e-money

    - Create wallet
    - Edit wallet
    - Delete wallet
    - View wallet list

5. Category
Classify user's transaction based on category, for example "Food", "Electric Bill", "Gym", etc

    - Create category
    - Edit category
    - Delete category
    - View category list

6. Budget Tracker
Track and monitor user's expense based on a spesific category

    - Plan budget
    - Track budget
    - Edit budget plan
    - Delete budget plan
    - View budget plan detail
    - View budget plan list
    - View budget plan analytics report
    - View AI powered advice on budget plan

7. Saving Planner
Create, deposit, and monitor user's saving plan

    - Plan saving
    - View saving progress
    - Edit saving plan
    - Delete saving plan
    - View saving plan detail
    - View saving plan list
    - View saving plan analytics report
    - View AI powered advice on saving plan

8. Dashboard
View current user's financial report

    - View current actual balance
    - View current available balance
    - View transaction plan reminder
    - View transaction analytics report summary
    - View budget analytics report summary and AI powered advice
