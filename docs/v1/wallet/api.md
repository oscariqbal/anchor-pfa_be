# Wallet

## API Design

---

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST |  `/wallets` | Create a wallet |
| PATCH | `/wallets/:id` | Edit a wallet |
| DELETE | `wallets/:id` | Delete a wallet |
| GET | `/wallets/:id` | View a wallet
| GET | `/wallets` | View all wallets |
