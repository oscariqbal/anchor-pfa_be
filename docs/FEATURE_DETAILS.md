## Feature Details
1. **Authentication**

    Ensure that users access the appropriate data and that data is accessed by the appropriate users.

    | Details | Objective | Input | Precondition | Process | Output |
    |---------|-----------|-------|--------------|---------|--------|
    | Create account | 
    | Read account information |
    | Edit account information |
    | Remove account |

2. **Transaction Record**

    Record user's transactions and view all transaction over a specific period

    | Details | Objective | Input | Precondition | Process | Output |
    |---------|-----------|-------|--------------|---------|--------|
    | Record income |
    | Edit income record |
    | Delete income record |
    | Record expense |
    | Edit expense record |
    | Delete expense record |
    | Record transfer |
    | Edit transfer record |
    | Delete transfer record |
    | Record saving allocation |
    | Edit saving allocation record |
    | Record saving release |
    | Edit saving release record |
    | View record detail |
    | View record list |
    | View transaction analytics report |
    | View AI powered advice on transaction |

3. **Transaction Planner**

    Plan user's transactions and view all planned transaction

    | Details | Objective | Input | Precondition | Process | Output |
    |---------|-----------|-------|--------------|---------|--------|
    | Plan income |
    | Edit income plan |
    | Delete income plan |
    | Plan expense |
    | Edit expense plan |
    | Delete expense plan |
    | Plan transfer |
    | Edit transfer plan |
    | Delete transfer plan |
    | View plan detail |
    | View plan list |
    | Realize plan |
    | Cancel plan |

4. **Wallet Management**

    Manage wallet to classify user's money position based on wallet type exist (bank, cash, e-money), for example "BCA" for bank, "Black Wallet" for cahs, and "DANA" for e-money

    | Details | Objective | Input | Precondition | Process | Output |
    |---------|-----------|-------|--------------|---------|--------|
    | Create wallet |
    | Edit wallet |
    | Delete wallet |
    | View wallet list |

5. **Category Management**

    Manage category to classify user's transaction based on category, for example "Food", "Electric Bill", "Gym", etc

    | Details | Objective | Input | Precondition | Process | Output |
    |---------|-----------|-------|--------------|---------|--------|
    | Create category |
    | Edit category |
    | Delete category |
    | View category list |

6. **Budget Tracker**

    Manage, track and monitor user's expense based on a spesific category

    | Details | Objective | Input | Precondition | Process | Output |
    |---------|-----------|-------|--------------|---------|--------|
    | Plan budget |
    | Track budget |
    | Edit budget plan |
    | Delete budget plan |
    | View budget plan detail |
    | View budget plan list |
    | View budget plan analytics report |
    | View AI powered advice on budget plan |

7. **Saving Planner**

    Manage and monitor user's saving plan and progress

    | Details | Objective | Input | Precondition | Process | Output |
    |---------|-----------|-------|--------------|---------|--------|
    | Plan saving |
    | View saving progress |
    | Edit saving plan |
    | Delete saving plan |
    | View saving plan detail |
    | View saving plan list |
    | View saving plan analytics report |
    | View AI powered advice on saving plan |

8. **Dashboard**

    View current user's financial report

    | Details | Objective | Input | Precondition | Process | Output |
    |---------|-----------|-------|--------------|---------|--------|
    | View current actual balance |
    | View current available balance |
    | View transaction plan reminder |
    | View transaction analytics report summary |
    | View budget analytics report summary and AI powered advice |
